# ⑥ 大三第二学期

> 专业选修与工程实践为主。**软件工程**和**编译原理**是典型硬课，同时课程设计与生产实习开始占用大量时间。

## 📚 课程一览

| 课程 | 内容与难点 | 难度 |
| :--- | :--- | :---: |
| [软件工程](./软件工程/) | 需求分析、设计模式、UML、测试方法。文档能力在这里训练。 | ⚠️ 中 |
| [编译原理](./编译原理/) | 词法分析、语法分析、语义分析、代码生成。难度高但价值大。 | 🔥 难 |
| [专业选修课](./专业选修课/) | 按方向选修，建议结合毕业去向选择，不要只挑水课。 | ⚠️ 中 |
| [课程设计](./课程设计/) | 综合性强的实践环节，选题和文档决定最终评价。 | ⚠️ 中 |
| [生产实习](./生产实习/) | 进入企业或实验室实践，出勤与实习报告是主要依据。 | ✅ 易 |

## 💡 学期总攻略

::: tip 这一学期怎么过
1. **编译原理啃下来收获最大** —— 词法、语法、语义分析，能真正理解程序怎么跑起来。
2. **软件工程重文档与流程** —— 需求、设计、测试，别只当理论课听。
3. **课程设计要选能写进简历的题目** —— 与其做十个 toy 项目，不如做一个完整的。
4. **保研冲刺期** —— 夏令营材料、推荐信、成绩单都要在这学期准备好。
:::
