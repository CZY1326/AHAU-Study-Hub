# ③ 大二第一学期

> 进入专业基础课阶段。**线性代数**与**概率论**是后续几乎所有专业课的数学基础，数据结构则是编程能力的分水岭。

## 📚 课程一览

| 课程 | 内容与难点 | 难度 |
| :--- | :--- | :---: |
| [线性代数](./线性代数/) | 矩阵运算、行列式、特征值、二次型。计算需细心，概念需清晰。 | ⚠️ 中 |
| [概率论与数理统计](./概率论与数理统计/) | 随机变量、常见分布、参数估计、假设检验。公式多。 | ⚠️ 中 |
| [马克思主义基本原理](./马克思主义基本原理/) | 思政必修，偏理论抽象，建议结合案例理解。 | ✅ 易 |
| [数据结构](./数据结构/) | 线性表、树、图、查找、排序。算法思想 + 代码实现并重。 | 🔥 难 |
| [大学英语3](./大学英语3/) | 分级教学延续，部分学校此阶段开放六级。 | ⚠️ 中 |

## 💡 学期总攻略

::: tip 这一学期怎么过
1. **线代靠理解变换本质** —— 矩阵、特征值、向量空间，别只背计算步骤。
2. **概率论与数理统计要区分概念** —— 分布、期望、方差、大数定律容易混，画思维导图。
3. **数据结构必须写代码实现** —— 链表、栈、队列、树、排序，手写一遍胜过看十遍。
4. **开始考虑方向** —— 大三要选专业方向，这学期多了解各方向在学什么。
:::
