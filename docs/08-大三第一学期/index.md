# ⑤ 大三第一学期

> 专业核心课最密集的一学期。数据库、计算机网络、操作系统三门通常同时开，课业强度达到峰值。

## 📚 课程一览

| 课程 | 内容与难点 | 难度 |
| :--- | :--- | :---: |
| [数据库原理](./数据库原理/) | 关系模型、SQL、范式、事务与索引。SQL 必须能独立写。 | 🔥 难 |
| [计算机网络](./计算机网络/) | 分层模型、TCP/IP、路由与交换。抓包实验帮助极大。 | 🔥 难 |
| [操作系统](./操作系统/) | 进程、线程、调度、内存管理、文件系统。概念抽象，需反复看。 | 🔥 难 |
| [专业核心课（按学院自选）](./专业核心课（按学院自选）/) | 各学院设置不同，以本专业培养方案为准。 | ⚠️ 中 |
| [习近平新时代中国特色社会主义思想概论](./习近平新时代中国特色社会主义思想概论/) | 思政必修，紧跟时事，理解框架即可。 | ✅ 易 |

## 💡 学期总攻略

::: tip 这一学期怎么过
1. **三门核心课都要动手实验** —— 建库写 SQL、抓包分析、跑进程调度，实验分往往占比不小。
2. **提前想清楚毕业去向** —— 保研看排名，考研要开始规划，就业要攒项目。
3. **别在大三上挂科** —— 此时挂科对保研资格和评优的影响最直接。
4. **开始整理自己的项目** —— 课程设计别做完就丢，将来写简历全靠它。
:::
