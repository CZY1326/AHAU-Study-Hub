# 选修通识课

> **所属模块**：学业专栏

### 选修通识课

1.抢选修课

登录智慧安农-本科教务-选课-自主选课

二.选修课推荐

学长上过的选修课

三.注意事项

1.校公选课成绩绩点计入学生总成绩绩点，因此学生选课时应慎重。

2.网络公选课不安排课程退改选。

3.成绩构成

①无助教

课程视频学习（40%）+课堂测验（15%）+期末线上考试（45%）。

②有助教

课程视频学习（40%）+课堂测验（15%）+期末线上考试（30%～35%）+主观题考核（15%～10%）。

因此选课后，学生应关注学校第7-8周发布的网络公选课助教信息并加入相关课程的学习群，以便及时了解助教老师安排的线上答疑、互动、主观题考核等事宜。

4.根据人才培养方案，2023、2022、2021级本科学生公共选修课模块须修满12学分，四年内修完；2024级本科学生公共选修课模块须修满8学分，四年内修完。

5.特别注意

①本科学生应至少修够2学分的“艺术美育”类课程方能毕业；艺术美育类课程名称后面均有“（美育）”的标识，如《****（美育）》。

②本科学生应至少修够1学分的“四史”类课程方能毕业；“四史”类课程名称后面均有“（四史）”的标识，如《****（四史）》。

③本科学生应至少修够1学分的“AI”类课程方能毕业；“AI”类课程名称后面均有“（人工智能）”的标识，如《****（人工智能）》

④剩余的学分课程自行选择

6.公共选修课考核不合格的学生，均不安排补考和重修。学生可在以后的学期里选修其他公选课，修够本专业年级人才培养方案中规定的公共选修课模块学分即可。
