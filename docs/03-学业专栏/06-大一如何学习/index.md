# 大一如何学习

> **所属模块**：学业专栏

### 大一如何学习

①大一会有一年的晚自习，一般到接近期末的时候结束。个别学院还会延长晚自习时间。

② 必修成绩和综测成绩是转专业、推优入党、奖学金、评优选拔、竞选学生干部、保研考研等的重要参考依据

③最好别挂科，对评优评奖转专业等有影响。考试挂科的话，有一次开学前提前来校补考的机会。补考未过的话，必修课程就需要交钱重修。

④上课带手机、课本、黑笔，本子四样能应付大多数课程。

⑤平时上课认真听，按时完成作业，不缺课，期末的时候认真复习，看看本课程题库，挂科是很难的。

⑥许多课程基本都可以旁听

⑦有辅修学位，没有双学位，参见下列文件。

⑧无针对英语的分级考试或分班

⑨大一入学后，可以考CET-4考试(英语4级)

ⅰ)若高考英语单科在125分以上，等待教务处通知，可在第一学期报考12月份的CET-4考试。

ⅱ)若高考英语成绩在125分以下，需要第一学期大学英语1成绩在70分以上，可在第二学期报考6月份的CET-4考试。
