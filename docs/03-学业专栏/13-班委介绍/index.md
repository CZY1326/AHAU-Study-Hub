# 班委介绍

> **所属模块**：学业专栏

### 班委介绍

⭐团支部、班委会是共青团和学生会在学生小班的基层组织，在班主任的领导和指导下负责班级（团支部）自身建设，民主管理班级（团支部）各项事务，推动班团一体化运行。原则上班团干部不超过7人，建议为团支书、班长（兼副团支书）、组织委员（兼生活委员)、宣传委员(兼文娱委员）、学习委员、心理委员、体育委员。重点工作包括：制定班级（团支部）管理规定、工作目标和计划，规范管理成员学习生活秩序、宿舍公共卫生、纪律与安全要求；加强学风建设，引导成员积极向德、智、体、美、劳全面发展；密切联系青年，发挥好学院、学校联系青年的基层桥梁纽带作用；做好团员发展、团费收缴、推优入党、三会两制一课、智慧团建等基础团务工作；在班主任的指导下，完成综合素质测评、奖助学金评定、评优评先、家庭经济困难学生认定等工作。

⭐班委选举

⭐1.一般情开学前会选临时班委\临时负责人，军训结束后，会召开班会进行班委选举，竞选者需要进行自我介绍和竞选发言，后全班投票决定

⭐⑴.竞选攻略

表现白己的能力和表达自己的承诺 ，收获同学们的信任适当地释放幽默感，拉进和同学的距离。模板：礼貌问好+名字+竞选职位+特长/自身优势+在这个职位能给班级带来的帮助+结束

eg.同学们好呀，我叫xx，来自内蒙古，对，我是骑马来到安农的，但是保安叔叔把马扣下了。今天，我竞选的职位是心理委员！心理委员是一个许多同学都向往的职务，因为它不只是一个称号，一个光环，它背后有着实质性的内容，与同学息息相关。所以，它需要的是一个细心体贴、观察入微的人来担当，我相信我有这个能力。如果竞选成功，我一定做好以下几点:认真学习并积极宣传大学生心理健康知识，在本班级积极开展心理健康教育和宣传。协助学校开展各种活动，注意发现同学出现的各种心理异常现象，给予力所能及的帮助，并及时向班主任、学校心理健康辅导教师反映。帮助有心理困难的同学及时前往心理咨询室接受心理辅导，负责向心理辅导教师提供同学的表现，以便加强对接受咨询的学生跟踪及反馈。如果我幸运当选的话，那以后24小时全天在线辅导咨询各种心理/情感问题;要是没当选的话，可能今晚我得先给自己辅导辅导一番啦~

⭐(3)各职能介绍

①班长

与班主任老师和班助对接，积极传达其意见和建议，关注各种班长对接群中的信息,及时向同学们转发校、院两级的各种活动和安排秉持着公平公正公开的原则，和贫困认定小组的成员一起完成本学年小班同学的贫困认定打分。

②团支书

组织几次团日活动，通知团支部的青年和团员积极参与团日活动督促团员们在智慧团建上转入团籍,整理团员们的团籍资科，交予组织部；到组织部自查团籍，通知团支部成员积极参与“青年大学习”的学习，统计参与人数参与班级的贫因认定。

③学习委员

统计班级日常学习事务；

负责建立优良学风，设计开展学风建设工作；

负责监督班级同学学习情况，在班内起带头作用；

负责收发课堂作业、记录成绩，与任课老师交流班内学习情况；

领取四六级证书并发放；

领取教材并发放；

参与奖助学金评比；

转发重要通知，对接老师；

对接二课协助自主申请；

④组织委员

对接学院实践部，组织同学们举办社会实践和公益活动，了解实践活动详情，为同学们解答疑惑，给同学们提供帮助与服务。

管理班费、与六位班委协助管理班级事务。

⑤宣传委员

负责班级微博、微信公众号、QQ的运营。

带领班上的同学一起撰写推文，团结大家组织团建。

⑥文体委员

鼓励同学们参加新生拔河赛

和其他班级文体委员密切沟通，开展了篮球友谊赛

帮助体育老师收集健身跑的数据

⑦心理委员

积极参加心理委员培训

辅助组织委员对官Q进行维护运营

当同学寻求心理辅导时，积极传播正能量，帮助解决问题并得到了不错的反馈
