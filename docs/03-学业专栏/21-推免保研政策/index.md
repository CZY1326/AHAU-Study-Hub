# 推免（保研）：推荐优秀应届本科毕业生免试攻读硕士学位研究生

> **所属模块**：学业专栏

### 保研

安徽农业大学具有保研资格，涉农专业保研率8%左右，全校整体保研率近7%，稳居安徽省属院校前三位！

⭐保研，全称是"保送研究生"，是指在本科阶段，学生因为学习成绩优异、科研能力突出或其他方面表现优秀，由学校推荐免试直接进入研究生阶段学习的一种选拔方式。保研通常需要学生在本科期间“综测和绩点”高→体现为<有较好的成绩，参与科研活动，获得一定的学术成果，或者有其他方面的特长和成就。>(推优免试)

⭐考研，即"研究生入学考试"，是指学生通过参加全国统一的研究生入学考试，包括初试和复试两个阶段，通过考试选拔进入研究生阶段学习的一种方式。考研通常需要学生在本科阶段有一定的学术基础，通过自学或参加培训等方式准备考试。

⭐保研和考研的主要区别在于：

1.选拔方式不同：保研是学校推荐免试，考研需要参加全国统一的研究生入学考试。

2.选拔标准不同：保研更注重学生的综合素质，包括学术成果、科研能力等；考研主要考察学生的学术基础和应试能力。

3.选拔范围不同：保研通常只针对本校或部分优秀学生，考研面向全国所有符合条件的考生。

4.选拔程序不同：保研需要经过学校推荐、专家评审等程序；考研需要经过初试、复试等环节。

5.影响因素不同：保研受学校政策、导师意愿等因素的影响较大；考研主要受个人努力和考试成绩的影响。

⭐总的来说，保研和考研都是选拔优秀学生进入研究生阶段学习的方式，但选拔方式、标准、范围等方面存在一定差异。

保研苦三年，更容易上岸顶尖名牌大学（浙大、交大、中国农大、科大等等），大四时相对轻松！

考研累一年，竞争也很激烈，我们学校的学生去南京农业大学、华中农业大学等211大学的很多！

在我们学校保研=绩点（75%）+科研加分（20%）+其他（5%），另外，保研同学一般都要过英语四六级（没过不能保研）

每个学院的保研政策大同小异，想要保研的同学大一就要重点关注。
