# 配套公众号与学习通

> **所属模块**：前言概要

资料原始来源是**超星学习通课程《安农学习时光》**（课程 ID 244549213）。学习通里放原始文件与通知，本站把它们整理成按学期可检索、可长期维护的结构，公众号同步发布整理进度与新增资料。

## 学习通课程

课程门户（网页版直接打开，登录学习通账号后即可查看目录、资料与通知）：

**[安农学习时光 · 学习通课程门户](https://mooc1.chaoxing.com/mooc-ans/course/portal/hRG5C5vWREn8t1KtkLwSwg==)**

手机端：打开学习通 App →「课程」→ 搜索课程名《安农学习时光》，或扫老师/群里发的课程码加入，之后在「资料」里下载原始文件。

::: tip 两个入口怎么选
- 想**按学期系统找资料、看避坑攻略**：留在本站，左侧边栏按学期展开即可。
- 想**看最新通知、拿未整理的原始文件、参与讨论**：去学习通课程门户。
:::
