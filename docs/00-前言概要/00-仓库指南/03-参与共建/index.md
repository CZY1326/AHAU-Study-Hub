# 参与共建

## 投稿方式

不需要会 Git，也不需要先加权限。

### 方式一：Pull Request（推荐）

1. 点右上角 **Fork**，复制一份到你的账号；
2. 在 Fork 里进入对应课程文件夹，点 **Add file** → **Upload files**；
   （要建新文件夹时，把上传文件名写成 `目录名/文件名`，GitHub 会自动建目录）
3. 上传后点 **Contribute** → **Open pull request**；
4. 等维护者审核合并。

放入 `课件/`、`试卷与答案/`、`复习资料/` 的文件会**自动出现在课程页清单里**，无需手动改页面。

### 方式二：Issue 代传

在 [Issues](https://github.com/CZY1326/AHAU-Study-Hub/issues) 发「资料投稿」，把文件拖进正文，维护者代传。

> 投稿时写一下 GitHub 用户名/昵称，方便记到贡献者名单；
> 含个人隐私、不想公开的资料不要直接发 Issue，先自行打码。

## 角色

| 角色 | 能做什么 | 需要会什么 |
| :--- | :--- | :--- |
| 浏览者 | 查看、下载资料 | 会打开网页就行 |
| 投稿者 | 把资料发给维护者，由维护者代传 | 不需要 GitHub，发 Issue 即可 |
| 共创者 | 直接上传、整理自己负责的学期/课程 | 会用网页版 GitHub 即可 |
| 维护者 | 管理权限、审核、处理侵权和结构问题 | 目前由 [@CZY1326](https://github.com/CZY1326) 负责 |

## 共创者（欢迎自荐）

本仓库目前由 [@CZY1326](https://github.com/CZY1326) 发起和维护。**不设固定名额**；如果你愿意长期负责某个学期或几门课，欢迎直接在 Issue 里说一声，合适的话会加你为 collaborator（Write 权限）。

> 普通投稿**不需要**加 collaborator；只有长期负责某个学期/课程的共创者，才会给 Write 权限。

### 怎么加入

1. 在 [Issues](https://github.com/CZY1326/AHAU-Study-Hub/issues) 说「我想参与维护」，写清楚：
   - GitHub 用户名；
   - 学院 / 专业 / 年级；
   - 想负责的学期或课程；
   - 大概能投入的时间。
2. 和维护者确认分工与规则（不用写申请信）；
3. 确认后接受 GitHub 邀请，即可直接上传；
4. 第一次上传前看一遍 [提醒与警告](../04-提醒与警告/) 和下面的规则。

## 共创者规则

- **先 Pull 再上传**：GitHub Desktop 先 `Fetch origin` → `Pull origin`；网页上传前先刷新，避免覆盖别人的提交。
- **只动自己负责的课程**：删除、重命名、移动整个文件夹，先在 Issue 说一声。
- **不重复上传**：同一份资料只放一个地方。
- **控制体积**：单文件 ≤ 50 MB，超过的到 [06-资料链接](/06-资料链接/) 登记外链；全库控制在 1 GB 以内。
- **不动脚本生成的内容**：课程页的资料清单区间、README 的目录树区间都由脚本维护。
- **加新课程走脚手架**：改 `scripts/scaffold.mjs` 的课程表后跑 `npm run scaffold`，不要手工建课程目录。
- **Commit 说明**：`添加 课程名 学年学期 资料类型` / `修正 课程名 文件名` / `删除 课程名 过期资料`。
