# 前言概要

> 这一页讲清楚三件事：**这是什么**、**怎么用**、**你能帮上什么忙**。

## 这是什么

**安农学习时光** 是一个面向安徽农业大学本科生的课程资料共享知识库，把散落在网盘、群聊、学长学姐硬盘里的东西，整理成结构清晰、可搜索、可持续更新的站点。

它替代的是「加群 → 私聊求资料 → 收到一个过期网盘链接」这套流程。

## 怎么用

::: tip 四条路径
1. **新生**：先去 [新生专栏](/01-新生专栏/) 把报到、宿舍、军训的事办完。
2. **找资料**：按左侧边栏的学期展开，找到课程 → 进入 `课件 / 试卷与答案 / 复习资料`。
3. **查经验**：想知道某门课好不好过、某位老师怎么考，直接看课程页里的「避坑指南与复习攻略」。
4. **看原始文件**：去超星学习通课程 [安农学习时光](https://mooc1.chaoxing.com/mooc-ans/course/portal/hRG5C5vWREn8t1KtkLwSwg==)，通知与未整理的资料都发在那边。
:::

站点左上角的**搜索框**支持全文检索，课程名、老师名、关键词都能搜。

## 资料摆放约定

| 体积 | 放哪里 | 原因 |
| :--- | :--- | :--- |
| **< 60 MB**（普通课件、PDF、真题） | 直接提交进仓库 | GitHub 单文件硬上限 100 MB，60 MB 是安全线 |
| **> 60 MB**（高清扫描件、录屏视频） | 压缩或按页段分割成多个分卷后入库 | 单文件控制在 60 MB 内，克隆快、下载稳 |

每门课目录固定三个子目录：

- `课件/` —— PPT、讲义、课堂板书
- `试卷与答案/` —— 期末真题、模拟卷、答案
- `复习资料/` —— 复习提纲、重点整理、笔记
