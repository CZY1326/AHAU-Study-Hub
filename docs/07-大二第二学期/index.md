# ④ 大二第二学期

> 专业课比重上升，**面向对象程序设计**和**离散数学**是重点。这学期开始要为大三的专业核心课打基础。

## 📚 课程一览

| 课程 | 内容与难点 | 难度 |
| :--- | :--- | :---: |
| [大学英语4](./大学英语4/) | 大学英语收尾课程，部分学校要求通过六级方可毕业。 | ⚠️ 中 |
| [离散数学](./离散数学/) | 集合论、图论、数理逻辑。抽象但规律性强，做题找套路。 | ⚠️ 中 |

| [毛泽东思想和中国特色社会主义理论体系概论](./毛泽东思想和中国特色社会主义理论体系概论/) | 思政必修，内容较多，建议按时间与主题双线索梳理。 | ✅ 易 |
| [专业导论](./专业导论/) | 了解本专业的课程体系与就业方向，多听多记。 | ✅ 易 |

## 💡 学期总攻略

::: tip 这一学期怎么过
1. **面向对象重在思想** —— 封装、继承、多态不是语法点，是设计方式，多写小项目体会。
2. **离散数学是理论地基** —— 集合、图论、逻辑，对后续算法与编译原理帮助极大。
3. **英语课收尾** —— 英语 4 通常是最后一门大学英语，六级尽早拿下。
4. **准备课程设计** —— 有些课会要求小项目，提前组队、提前选题。
:::
