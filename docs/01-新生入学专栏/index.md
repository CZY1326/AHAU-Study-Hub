# 新生入学专栏

> 从收到录取通知书到军训结束，这一页覆盖你最容易踩坑的每个环节。

## 入学前准备

::: tip 必备材料清单
- **录取通知书**原件（多复印几份，报到、办卡都用得上）
- **身份证** + 复印件若干
- **高考准考证**（部分环节会查验）
- **户口迁移证**（自愿迁户口的话，务必在有效期内办好）
- **党团组织关系**转接材料
- **一寸/二寸证件照**各 8 张以上（红底蓝底都备一些，电子版存手机）
- **银行卡**（学校一般会随通知书寄一张，激活后用于缴费）
:::

### 行李要不要全带？

不建议。被褥、脸盆、衣架这类**体积大又便宜**的东西，到学校周边超市买更划算，价格差不多还省运费。真正值得从家带的：**换季衣物、常用药、笔记本电脑、重要证件**。

## 学长学姐的话

::: tip 几句实话
1. **别急着买学长推销的东西**。开学季上门推销的英语报、被褥、电话卡，八成比外面贵。
2. **第一个月别报太多社团**。先摸清课业强度，再加社团也不迟。
3. **把辅导员和班主任的联系方式存进手机**，办手续、请假都要找他们。
4. **尽早搞懂教务系统**怎么选课、怎么查成绩，这是四年里最高频的操作。
:::
