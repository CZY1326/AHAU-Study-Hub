# 智慧安农 APP

> **所属模块**：生活专栏

### 智慧安农APP

1.智慧安农

点击链接下载安装或使用手机浏览器扫描二维码下载安装。

![插图](./images/ac51dc91d2fd0cf36a2117ab6abadc58.jpg)
安卓、iOS用户扫码下载APP

2. 非纯血鸿蒙系统（兼容安卓）需要退出纯净模式安装，具体方法请参阅《用网技巧24-非纯血鸿蒙系统安装智慧安农相关操作》

[http://xxb.ahau.edu.cn/info/1181/4761.htm](http://xxb.ahau.edu.cn/info/1181/4761.htm）)

3.鸿蒙移动端用户想要使用智慧安农移动端服务，建议下载安装企业微信，加入“安徽农业大学”企业微信组织，具体方法请参阅《用网技巧26-师生加入安徽农业大学企业微信操作说明》[http://xxb.ahau.edu.cn/info/1181/5971.htm](http://xxb.ahau.edu.cn/info/1181/5971.htm))

或扫码查看。

![插图](./images/9be5dcdf4941060c553676ce7616ed75.jpg)
鸿蒙用户扫码查看下载加入企业微信方法
