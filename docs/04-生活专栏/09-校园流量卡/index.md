# 校园流量卡

> **所属模块**：生活专栏

### 校园流量卡

“校园卡”真正的含义是“校园一卡通”，“校园网”一般指校园内网，学校是有宽带(5元每月)和无线网(覆盖大部分教学楼和宿舍)，这两者是直接接智慧安农，所以学校流传图书馆机房抢课快的说法。

而三大运营商提供的“校园卡”，实际上是各大运营商针对在校学生推出的优惠套餐卡，为学生提供优惠的上网流量。校园周边一定范围内（通常为1-2公里，学校基站覆盖的这2km区域才可以用校园流量，方便称呼称为校园网，这和“校园内网”是有区别的，校园内网是有自己的服务器的局域网，用于学校内部信息交流，智慧安农上所有的网络服务如迎新系统、本科教务、校园一卡通都是基于此，他不会和外界运营商直接联系，想访问校园内网都需要挂VPN)
这个校园流量是省内高校通用的，所以如果有人和你说校园卡抢课快请不要相信。(校园流量卡和普通流量卡没有区别，它只是流量对学生来说优惠，所以也不存在没有校园卡抢不了课。)而且本校的基站是共享的，所以三大运营商的信号差别不会太大。

因此，在学校没有连学校的WiFi、宽带而是用运营商流量卡，或者根本不在学校。都需要VPN，才能进入校园内网，进入智慧安农。

你们已经经历过抢宿舍，其实抢课也一样。挂上VPN，访问智慧安农。无论抢啥和网速有关系，但确实不大。其实还有自己设备的影响，最关键的是校服务器无法支持大量学生同时访问“校园内网”。(12306国庆、春节抢火车票也会闪退，大麦等抢演唱会门票也要手快。)

其实大家发生网络拥堵进不去，也不必过于担心。宿舍都有得住，课也都有得选。只是在于能不能抢到自己喜欢的。
