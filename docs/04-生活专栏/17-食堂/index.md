# 食堂

> **所属模块**：生活专栏

### 食堂

⭐一.学校设有六个食堂：

校内有西苑，东苑，欣苑，北苑；

校外公寓有丰泽和思源

①学校食堂菜色多样，价格合理，你可以永远相信安农大的食堂，每一个餐厅都有不一样的惊喜

②早餐一般有包子，面包，烧卖，紫薯，烧饼，玉米，豆浆，牛奶等各种甜食面点，种类真的很丰富，美食琳琅，菜品丰富多样，就餐环境温馨

③ 午餐晚餐一般有荤素套餐，冒菜，小闷锅，麻辣香锅，馄饨，热干面，瓦香鸡，麻辣烫，披萨，蛋包饭等各种样式，口味多样，种类齐全，任君挑选。

⭐二.友情提醒

中午和晚上下课后那段时间是食堂人流高峰期

①学长学姐衷心建议：珍爱生命，错峰恰饭！

②抢饭时可能会有人用书包等个人物品占座，以至于去晚了可能找不到合适的座位

③如果实在没位置，宝子们也可以打包带回寝室~

⭐三.价格

① 单个餐品一般不会超过15元(麻辣烫麻辣香锅依量而定)

②分量足，价格实惠

③食堂白天开放，可坐可自习可小组谈论（或者和朋友一起玩桌游~）

⭐四.饭卡充值的方法

1.在智慧安农中的一卡通上通过绑定的银行卡进行转账；

2.在圈存机上扫码（微信/支付宝）进行充值。
