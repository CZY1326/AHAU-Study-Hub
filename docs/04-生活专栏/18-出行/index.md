# 出行

> **所属模块**：生活专栏

### 出行

安农大位于一环长江西路130号，地理位置实在是太好啦，交通特别便利！

⭐地铁：

东门一分钟乘坐地铁2号线。

安农大站D口离东门很近。

乘坐地铁2号线可换乘3号线，5号线。

小西门官亭路小吃街尽头有三里庵地铁站。

北二门的校外公寓离地铁口较远，步行15-20分钟。建议扫一辆助力车。

⭐公交：

116路、136路、3路、快速公交4号线、114路、127路、17路、125路、59路、51路、122路、21路东线环线、119路、21路西线环线、149路。

这些线路覆盖了合肥市的主要区域，可以满足大多数出行需求。

公交22路的首末班时间：起点站首末车时间为06:00-21:30，终点站首末车时间为06:00-22:001。

合肥690路公交车的首末班时间：无论是从城关枢纽站到山南客运站，还是相反方向，首末班车时间均为06:00-18:002

⭐ 共享单车：

校外：东门、北二门、北三门、北一门附近均有共享单车停车点，北二门最为方便。校外有助力车也有自行车。校内只有青桔共享自行车。校外的车不能骑进来，校内的车不能骑出去。

⭐哈啰单车（共享单车）：

普通时段：1.5元/30分钟。

高峰时段（07:00-10:00 和 17:00-20:00）：1.8元/30分钟。

起步价（助力车）：1.5元/8分钟，之后每超出10分钟收费1.5元。

车辆调度费（还车位置不规范产生的费用）：根据不同情况，费用在5元到30元不等。

⭐哈啰助力车（共享电动车）：

起步价：1.5元/8分钟。

超出起步价后：1.5元/10分钟。

车辆调度费：同上。

此外，还有多种骑行套餐可供选择，例如助力车7天3次卡、7天5次卡、15天10次卡等，价格分别为5.8元、7.9元、16.5元等

⭐到合肥站(火车站)

(1)地铁：乘坐地铁2号线到大东门站，然后换乘地铁1号线到合肥站。全程约1小时，票价3元。(方向可以在地铁站或高德看地铁运行图)

（2)公交车：从北二门出去，奥林花园站可乘坐114路可直达火车站。费用两元，可选择现金、微信、支付宝支付。（微信支付：微信搜索小程序“乘车码”会出现合肥通乘车码，扫码即可；支付宝支付：选择城市服务→交通出行→合肥通电子公交卡→乘车码→扫码即可）。

打车/自驾：距离约13.7公里，耗时约27分钟，打车费用约28元。

⭐到合肥南站

地铁：乘坐5号线到三孝口站，换乘2号线到安农大站，然后步行到安徽农业大学。全程约15分钟，票价3元。

公交:从北二门出去，奥林花园站可乘坐114路可直达合肥南站。费用两元，可选择现金、微信、支付宝支付。

打车/自驾：距离约14.1公里，耗时约28分钟，打车费用约28元。

⭐ 到新桥机场

机场巴士:机场巴士1号线在大西门下车。全程约1小时25分钟，票价28元。

打车/自驾：距离约54.9公里，耗时约49分钟，打车费用约125元。

总结栏

安农大附近的交通真的绝，全国唯一一所一环内的大学太香了，来了就知道了。
