# 🌱 选修和通识课

> 校公选、通识课的口碑与避坑 —— 把「给分好不好、作业多不多、值不值得选」讲清楚。

## 怎么挑选修课

::: tip 三条实用原则
1. **看考核方式**：论文 / 开卷 / 闭卷差别巨大。想省时间就避开闭卷。
2. **看作业量**：有些课每节课都留小作业，一学期下来比必修还累。
3. **看给分分布**：有的课「优秀率」高，有的课卡在 80 分上不去，差一门课可能就差一个奖学金档。
:::
