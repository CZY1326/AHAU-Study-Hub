# ① 大一第一学期

> 大学第一学期，课业压力不算最大，但**适应节奏**比刷分更重要。高数是这学期最容易挂的课，务必从第一节课就跟着走。

## 📚 课程一览

| 课程 | 内容与难点 | 难度 |
| :--- | :--- | :---: |
| [高等数学A1](./高等数学A1/) | 5 学分，闭卷，挂科率最高的课之一。重点：极限、导数、不定积分、定积分应用。 | 🔥 难 |
| [大学英语1](./大学英语1/) | 分级教学，考核含听力与口语。四级词汇从这学期开始背。 | ⚠️ 中 |
| [农业概论](./农业概论/) | 农科特色通识课，以记忆与理解为王，考前突击效率高。 | ✅ 易 |
| [思想道德与法治](./思想道德与法治/) | 思政必修，平时分占比高，期末多为开卷或论文。 | ✅ 易 |
| [计算机基础](./计算机基础/) | Office 与计算机常识，实操题为主，多做几套就稳。 | ✅ 易 |
| [体育1](./体育1/) | 体能 + 专项，出勤就是分数，别缺勤。 | ✅ 易 |

## 💡 学期总攻略

::: tip 这一学期怎么过
1. **高数 A1 是重中之重** —— 学分高、挂科率高，每周至少留 4 小时做课后题，别攒到期中。
2. **英语别丢** —— 四级尽早考，趁着高中底子还在。
3. **思政课别小看** —— 平时分占比高。点名缺勤、作业漏交是最常见的失分点。
4. **第一学期定基调** —— 绩点从这学期开始累计，开学松劲儿后面很难追。
:::
