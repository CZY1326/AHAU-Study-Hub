## 🎭 社团与学生组织

::: tip 选择的思路
- **兴趣类社团**（摄影、音乐、骑行）用于放松，加 1–2 个就够。
- **职能类组织**（学生会、社团联合会）能锻炼办事能力，但会议和任务较多，要评估自己的时间。
- 别为了「简历好看」硬撑多个组织，到大二会同时被课业和社团压垮。
:::

::: warning 待补充
- 各社团招新时间与门槛
- 哪些社团活动多、哪些比较轻松
:::
