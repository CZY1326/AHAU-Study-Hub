## 📌 选课

::: tip 选课的基本策略
1. **先看培养方案**，确认哪些是必修、哪些是选修、毕业需要多少学分。
2. **必修课优先排**，专业课别和重要公共课撞时间。
3. **选修课看给分口碑**，不要只看名字好听 —— 见 [12-选修和通识课](/12-选修和通识课/)。
4. **抢课要有备选**，热门课满员是常态，准备 2–3 个替代方案。
:::

## 📊 绩点与成绩

::: tip 绩点怎么影响你
- **保研**：绩点排名是硬门槛，通常看前五或前六学期的加权成绩。
- **奖学金**：评定几乎都以绩点为基础。
- **出国 / 交流**：GPA 是对方学校的第一道筛选。
- **就业**：部分国企、银行网申会卡成绩排名。
:::

## ✍️ 考试与学术诚信

::: danger 底线问题
考试违纪、作弊的代价极高：**记过以上处分会取消学位、影响保研与考公政审**，且通常不可撤销。
不要把「小抄」「手机查答案」当成侥幸，监考规则比你以为的严。
:::
