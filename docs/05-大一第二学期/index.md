# ② 大一第二学期

> 课业明显加重的一学期：高数进入多元微积分，**C 语言**是很多人第一次真正写代码，大学物理同时开课。

## 📚 课程一览

| 课程 | 内容与难点 | 难度 |
| :--- | :--- | :---: |
| [高等数学A2](./高等数学A2/) | 多元函数微积分、重积分、级数。计算量大，需要稳定练习。 | 🔥 难 |
| [大学英语2](./大学英语2/) | 延续分级教学，四级考试通常在本学期或下学期。 | ⚠️ 中 |
| [C语言程序设计](./C语言程序设计/) | 编程入门课。指针、数组、函数、结构体是核心，务必上机实操。 | 🔥 难 |
| [大学物理](./大学物理/) | 力学 / 电磁学为主，公式多、变形灵活，建议整理公式手册。 | ⚠️ 中 |
| [中国近现代史纲要](./中国近现代史纲要/) | 思政必修，时间线清晰，梳理框架后记忆效率高。 | ✅ 易 |
| [体育2](./体育2/) | 延续体育 1，保持出勤即可。 | ✅ 易 |

## 💡 学期总攻略

::: tip 这一学期怎么过
1. **C 语言一定要亲手敲代码** —— 只看书不动手，期末上机必崩。指针和数组是分水岭。
2. **高数 A2 转向多元与级数** —— 空间想象和公式记忆并重，刷题量决定分数。
3. **大学物理要抓公式推导** —— 死记结论没用，理解物理过程才能做变形题。
4. **这学期开始准备四级** —— 大部分学校要求大二前通过。
:::
