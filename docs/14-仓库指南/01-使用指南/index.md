# 使用指南

## 1. 找课

### 在网页版找（推荐）

访问 [安农学习时光](https://czy1326.github.io/AHAU-Study-Hub/)：

- 顶部导航按「学期 / 选修通识 / 链接库」进入，左侧目录再点具体课程；
- 右上角**搜索框**可直接搜课程名、老师名（缩写）、文件名，例如「高等数学」「期末试卷」。

### 在 GitHub 上找

- 打开仓库首页，按键盘上的 `t` 打开 **Go to file**，输入课程名或文件名；
- 或在 GitHub 搜索框输入：

```text
repo:CZY1326/AHAU-Study-Hub 高等数学
```

- 不知道课程在哪个学期？看 [分类与命名](../02-分类与命名/) 的完整目录树。

## 2. 在线看

- 每门课的资料都列在课程页的「资料清单」表格里，点**在线查看**或**下载**即可；
- PDF、图片、视频可在浏览器直接预览；`.docx`、`.pptx`、`.zip` 需下载后用 Office、WPS 或解压软件打开；
- 课程页的「避坑指南与复习攻略」是学长学姐手写的重点提示，比文件本身更省时间，别错过。

## 3. 下载

### 只下载一个文件

在课程页资料清单里点对应文件的**下载**按钮；GitHub 网页上也可打开文件后点 **Download raw file**（找不到按钮就点 **Raw**，再 `Ctrl + S`）。

### 下载整个仓库

仓库首页绿色 **Code** → **Download ZIP**，解压即可。

### 只下载一个文件夹

GitHub 没有官方的「单文件夹下载」按钮，可以：

1. 下载整个仓库 ZIP，解压后只取需要的文件夹（推荐）；
2. 用 GitHub Desktop 克隆后复制；
3. 用 GitZip、DownGit 等第三方工具（注意文件安全）。

### 手机上

浏览、搜索、在线看 PDF 都没问题；下载 ZIP 和批量传资料建议用电脑。

## 4. 看更新

- 点仓库右上角 **Watch** → **All Activity**，有更新 GitHub 会通知你；
- 点 **Commits** 看每次补了什么资料；
- 点 **Star** 收藏，之后在个人主页 **Your stars** 里能找到。

## 5. 找不到资料怎么办

去 [Issues](https://github.com/CZY1326/AHAU-Study-Hub/issues) 点 **New issue**，标题写：

```text
[求助] 课程名 - 需要的资料类型
```

正文写：学院、专业、年级、课程名、需要的资料。

> 不要索要考试进行中的题目或答案；考完再求试卷。

大于 50 MB 的超大资源（整本教材扫描件、课程录屏等）统一登记在 [13-资料链接库](/13-资料链接库/)，先去那里翻翻。
