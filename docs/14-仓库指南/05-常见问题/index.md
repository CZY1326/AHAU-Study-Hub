# 常见问题

**Q：为什么没有我们学院的课？**
A：本站以园艺学院培养方案为蓝本整理，还没铺到所有学院。公共课和通识课部分是通用的，欢迎投稿；想系统铺某个学院的课，可以在 [参与共建](../03-参与共建/) 里自荐共创者，我们按学期一起补。

**Q：这门课的资料还在路上，正常吗？**
A：正常。课程目录已按培养方案全部建好，但很多课的课件/真题还在收集。你手上有**历年真题**或**老师的复习提纲**，欢迎提 PR 补进来 —— 那是价值最高的东西。

**Q：试卷没有答案，正常吗？**
A：正常。很多试卷是同学回忆或整理的，答案不一定有，也不保证正确。请以老师讲解为准。

**Q：下载后打不开怎么办？**
A：PDF 用浏览器或 PDF 阅读器；`.docx` / `.pptx` 用 Office 或 WPS；`.zip` 用系统解压或 7-Zip。手机打不开时，换电脑试试。

**Q：可以拿这些资料去卖吗？**
A：不可以。本仓库内容仅供学习交流，禁止商业使用、倒卖、付费引流。

**Q：可以整库转载吗？**
A：可以转载自己整理的部分，但请保留出处、署名，遵守 CC BY-NC-SA 4.0。第三方资料版权归原作者，转载前请自行确认授权。

**Q：我不是计算机专业，能上传吗？**
A：能。用网页版 **Add file** → **Upload files** 就行，不需要学 Git 命令。

**Q：上传错了、想删除怎么办？**
A：网页上打开文件 → 右上角 **Delete file**；文件夹可以在 GitHub Desktop 里删除后提交。不会操作就发 Issue，注明路径。

**Q：为什么资料清单不能手动编辑？**
A：课程页「资料清单」由脚本扫描三个资料目录自动生成，手改会在下次构建时被覆盖。把文件放进对应目录即可，清单会自动更新。

**Q：为什么大于 50 MB 的文件传不进来？**
A：约定单文件 ≤ 50 MB（GitHub 硬上限 100 MB，CI 会强制检查）。超大资源请到 [13-资料链接库](/13-资料链接库/) 登记网盘外链。

**Q：为什么老师名字都写成缩写？**
A：保护授课教师隐私、避免争议。所有对教师的评价一律用拼音首字母缩写（如 `W老师`、`LJ老师`）。

**Q：为什么用中文文件夹名？**
A：方便同学一眼看懂。只要不用空格和 `\ / : * ? " < > |` 这些特殊字符，GitHub 和站点对中文路径的支持都正常。

**Q：为什么 README 这么短？**
A：README 只放导航和最短说明；详细内容拆到 `docs/14-仓库指南/` 下的独立页面，点链接就能看。
