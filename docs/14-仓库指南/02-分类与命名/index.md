# 分类与命名

## 顶层模块

| 编号 | 模块 | 放什么 |
| :--- | :--- | :--- |
| `00` | 前言与基础概要 | 项目缘起、更新日志、学习通配套内容 |
| `01` | 新生入学专栏 | 报到流程、宿舍军训、必备清单、资助政策 |
| `02` | 大学生活专栏 | 食堂社团、校园网、快递出行、生活攻略 |
| `03` | 学业相关问题 | 培养方案、选课、绩点、保研考研 |
| `04` ~ `11` | 大一第一学期 ~ 大四第二学期 | 园艺学院培养方案对应的各学期课程 |
| `12` | 选修和通识课 | 校公选课的资料与给分口碑 |
| `13` | 资料链接库 | 大于 50 MB 资料的外链登记 |

> 课程目录以**园艺学院本科人才培养方案**为蓝本，其他学院同学可按图索骥，公共课与通识课部分通用。

## 完整目录

```text
docs/
├── 00-前言与基础概要/
├── 01-新生入学专栏/
├── 02-大学生活专栏/
├── 03-学业相关问题/
├── 04-大一第一学期/          # 学期模块，每门课一个文件夹
│   └── 高等数学Ⅲ/
│       ├── index.md          # 课程页：资料清单 + 避坑指南
│       ├── 课件/
│       ├── 试卷与答案/
│       └── 复习资料/
├── 05-...  到  11-大四第二学期/
├── 12-选修和通识课/
└── 13-资料链接库/
```

> GitHub 不保存空文件夹；上传第一份资料后，对应文件夹才会出现在网页上。

## 课程文件夹内部

每门课**固定三个资料子目录**，顺序为：

```text
课件 → 试卷与答案 → 复习资料
```

课程页 `index.md` 的「资料清单」由脚本 `npm run files` 自动生成 —— 把文件放进对应目录即可，**不要手动编辑清单区间**（`<!-- FILES:START -->
::: info 资料还在路上
这门课的课件 / 试卷与答案 / 复习资料暂未上传。
如果你手上有**历年真题**或**老师的复习提纲**，欢迎提 PR 补进来 —— 那是价值最高的东西。
:::
<!-- FILES:END -->` 之间的内容）。

新增课程不用手工建目录：由维护者改 `scripts/scaffold.mjs` 的课程表后跑 `npm run scaffold` 自动补齐。

## 命名规范

文件夹和文件名用中文、数字、下划线，**不要用空格**，也不要用 `\ / : * ? " < > |`。

### 课程文件夹

用教务系统里的正式课程名，不加年份、老师名、「资料」二字，也不带 `【】` 标签：

```text
高等数学Ⅲ
植物生理学
园艺植物育种学
```

### 资料文件

推荐格式：

```text
学年学期_课程名_资料类型_补充说明.扩展名
```

示例：

```text
2024-2025-1_高等数学Ⅲ_期末试卷_回忆版.pdf
2024-2025-1_高等数学Ⅲ_期末试卷_参考答案.pdf
第03章_导数与微分_课堂笔记.pdf
```

- `2024-2025-1` 表示 2024 年秋季学期；
- 试卷注明：期末/期中/补考/缓考、A/B 卷、回忆版、含答案/无答案；
- 扫描件尽量转 PDF，200～300 dpi；太大就拆分。

## 体积规则

| 情况 | 放哪里 |
| :--- | :--- |
| 单文件 < 50 MB | 直接提交进仓库对应课程目录 |
| 单文件 ≥ 50 MB | 到 [13-资料链接库](/13-资料链接库/) 登记网盘外链 |

- GitHub 单文件硬上限 **100 MB**，超限直接推送失败；
- CI 有 `npm run checksize` 强制 50 MB 上限，超了会被拦下；
- 尽量压缩扫描件、拆分章节，同一内容不要重复传，全库先控制在 1 GB 以内。

## 隐私检查

上传前检查：

- 姓名、学号、班级、成绩、身份证号、手机号、宿舍号；
- 作业/实验报告封面、页眉页脚、PDF 属性里的作者名；
- 聊天记录截图里的头像、昵称、群名；
- **对教师的评价一律用姓名拼音首字母缩写**（如 `W老师`、`LJ老师`），不要写全名。

有的话先打码或删除。
