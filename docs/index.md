## 课程资料

> 课程目录以**园艺学院本科人才培养方案**为蓝本整理；其他学院同学同样可以按图索骥，公共课与通识课部分通用。

| 学期 | 入口 | 主要课程 |
| :--- | :--- | :--- |
| 大一上 | [大一第一学期](/02-课程资料/01-大一第一学期/) | 高等数学Ⅲ、无机化学Ⅱ、大学英语 1 |
| 大一下 | [大一第二学期](/02-课程资料/02-大一第二学期/) | 有机化学Ⅱ、植物学、生物统计 |
| 大二上 | [大二第一学期](/02-课程资料/03-大二第一学期/) | 土壤肥料学、园艺植物栽培学、设施园艺学 |
| 大二下 | [大二第二学期](/02-课程资料/04-大二第二学期/) | 园艺植物育种学、普通遗传学、植物生理学 |
| 大三上 | [大三第一学期](/02-课程资料/05-大三第一学期/) | 病虫害防治、无土栽培学、储藏加工学 |
| 大三下 | [大三第二学期](/02-课程资料/06-大三第二学期/) | 智慧园艺、品质与安全、方向实习Ⅰ |
| 大四上 | [大四第一学期](/02-课程资料/07-大四第一学期/) | 方向实习Ⅱ、综合性设计性大实验 |

| 公选 | [公选课外](/05-公选课外/) | 公选、专业选修与课外资料 |

## 参与贡献

如果你也有安农的优质资料，欢迎提交 Pull Request —— 无论是补一份真题、修一个死链，还是加一条避坑心得，都算数。

:::
