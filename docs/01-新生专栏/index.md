# 新生专栏

> 从收到录取通知书到军训结束，这一页覆盖你最容易踩坑的每个环节。

## 入学前准备

::: tip 必备材料清单
- **录取通知书**原件（多复印几份，报到、办卡都用得上）
- **身份证** + 复印件若干
- **高考准考证**（部分环节会查验，报到当天要现场核验）
- **户口迁移证**（自愿迁户口的话，务必在有效期内办好；安徽省内只需带户口本原件，省外才需要迁移证）
- **党团组织关系**转接材料（团员档案：入团志愿书、团员证）
- **一寸/二寸证件照**各 8 张以上（红底蓝底都备一些，电子版存手机）
- **银行卡**（学校一般会随通知书寄一张，激活后用于缴费）
:::

### 行李要不要全带？

不建议。被褥、脸盆、衣架这类**体积大又便宜**的东西，到学校周边超市买更划算，价格差不多还省运费。真正值得从家带的：**换季衣物、常用药、笔记本电脑、重要证件**。

分类打包清单（生活用品 / 学习用品 / 军训用品 / 个人资料）见 [新生必备物品清单](./02-新生必备物品清单/)。

### 档案与户口

- **档案**：自带的话报到后交给班级辅导员；邮寄必须在 8 月 29 日前到校（合肥市长江西路 130 号 安徽农业大学档案馆，邮编 230036），**只收 EMS 或机要**，普通快递一律不收。
- **户口**：可以不迁。要迁的话，迁入地址写「合肥市蜀山区长江西路 130 号安徽农业大学」，身份证复印件上注明本人联系方式、血型和身高。
- **团组织关系**在正式入学后再转，先审档案再走「智慧团建」；党组织关系省内全程网办、省外需纸质介绍信。

## 宿舍与报到

### 报到三步走

以下节奏参考 2025 级，具体日期以你收到的通知书和学院通知为准。

| 步骤 | 时间 | 要做的事 |
| :--- | :--- | :--- |
| ① 预报到 | 8 月 25 日 9:00 起 | 进「智慧安农」→「迎新系统」，完善个人信息、**在线选宿舍**，系统生成报到二维码 |
| ② 到校核验 | 8 月 30、31 日 | 到**智慧广场东侧、图书馆西侧之间马路**的学院报到点，凭二维码核验录取通知书、身份证、准考证 |
| ③ 入住 | 现场 | 未缴费的用手机自助缴费；已缴费的直接到新生宿舍扫码入住 |

- **接站**：8 月 30、31 日 7:00—18:00，合肥火车站和合肥高铁南站出站口有校车；也可自己坐公交、地铁或打车到校。
- **来不了怎么办**：必须先向学校请假，假期一般不超过两周。**未经请假或逾期两周不报到，视为放弃入学资格**。
- 报到流程原文与各环节咨询电话见 [新生入学须知（2025 版）](./06-新生入学须知（2025版）/)。

### 宿舍在哪个区

学校宿舍分**南区（校内 X1—X16）**和**北区（校外合肥大学生公寓 G1—G20）**，选宿舍前先看清位置：

| 楼栋 | 位置 | 生活配套 |
| :--- | :--- | :--- |
| X1—X7 | 东门附近，近八教勤学楼、一运，大一上课最方便 | 东苑、北苑食堂；东门外霍山路小吃街、红府超市；外卖可放东门 |
| X8—X11 | 学校南边，近博学楼、图书馆 | 欣苑、西苑食堂；小西门官亭路美食街；出门可到之心城、国购 |
| X12—X16 | 北二门两侧，近图书馆、博学楼、智慧广场 | 北二门、北三门小吃街；X12—14 外卖填北二门架子，X15—16 填北三门架子 |
| G1—G20（北区） | 校外合肥大学生公寓 | 丰泽、思源两个食堂 |

各楼栋细节、食堂推荐和实拍见 [寝室情况简介](./03-寝室情况简介/)。

::: warning 这几项还没问到
床的尺寸（买床品前必须确认）、宿舍门禁时间、空调/热水/洗衣机的实际配置，目前资料库还没有可靠信息，等学长学姐补充后会写进 [寝室热水吹风机洗衣机](/04-生活专栏/05-寝室热水吹风机洗衣机/) 和 [寝室相关问题](/04-生活专栏/04-寝室相关问题/)。**床品先别急着在网上下单**，到校量过再买。
:::

## 军训

军训的时长、日程强度、免训/缓训申请条件，资料库里暂时是空白页（[新生军训](/04-生活专栏/03-新生军训/)），不编。能给的实用建议：**防晒霜提前买、备两双软鞋垫和运动袜、随身带水杯**，男生提前理发（军训期间查发型）。

校园方位图（含南北区宿舍位置）在 [寝室情况简介](./03-寝室情况简介/) 页内，[新生迎新](./07-新生迎新/) 里有南北区宿舍与迎新现场实拍。

### 从学校去车站

- **合肥火车站**：东门往北到干休二所站，或北二门外奥林花园站，坐 **114 路**直达；也可地铁 2 号线到大东门换 1 号线。
- **合肥南站**：地铁 **2 号线安农大站 D 口**（环球广场）进站，大东门换 1 号线或三孝口换 5 号线。

### 缴费与校园卡

学校不允许任何人直接向学生收取任何费用，所有收费走财政非税收入直缴系统。缴费入口：微信/支付宝/银联云闪付扫「校园一卡通微门户」码，或用[安农缴费微门户](https://ykt.ahau.edu.cn/zsan/web)（初始密码为身份证号后六位，遇 X 用 0 代替）。标准与操作详见 [学杂费标准及缴费方式](./04-学杂费标准及缴费方式/)。

## 学长学姐的话

::: tip 几句实话
1. **别急着买学长推销的东西**。开学季上门推销的英语报、被褥、电话卡，八成比外面贵。学校也明确禁止任何人进宿舍楼推销，遇到直接拒绝。
2. **第一个月别报太多社团**。先摸清课业强度，再加社团也不迟。
3. **把辅导员和班主任的联系方式存进手机**，办手续、请假都要找他们。
4. **尽早搞懂教务系统**怎么选课、怎么查成绩，这是四年里最高频的操作。
5. **只加官方群**。各学院有官方 QQ 群，陌生人拉的群、扫码进群一律别进，进去了也及时退。
:::
