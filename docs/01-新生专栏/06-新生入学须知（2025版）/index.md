# 新生入学须知（2025 版）

> **所属模块**：新生专栏

一、自助预报到。

通过访问“智慧安农”—“迎新系统”完成预报到。系统将于8月25日上午9:00开通，进入系统后完善个人信息，完成在线选宿舍等预报到，操作说明详见《安徽农业大学迎新系统使用指南》。



二、持录取通知书和学校规定的有关证件，按期到校办理入学手续。

因故不能按期入学者，应当向学校请假，请假期限一般不得超过两周。未经请假或请假逾期，除因不可抗力等正当事由外，超过两周不报到者，视为放弃入学资格。



三、报到时间、地点及流程。

1.报到时间：8月30、31日

2.报到地点：智慧广场东侧、图书馆西侧之间马路。

3.报到流程：新生通过迎新系统完成预报到，完成预报到的同学系统自动生成电子版报到二维码。报到当天凭报到二维码到学院报到点完成身份核验（现场核实录取通知书、身份证和准考证），未缴费的现场通过手机自助缴费，已缴费的直接到新生宿舍扫码入住。

4.更多信息，请及时关注微信公众号“安农e学工”（微信号：aauxsc）或学生处网站http://xgb.ahau.edu.cn。咨询电话：0551-65780064。



四、缴费注册。

新生应当按照国家、安徽省及学校相关规定缴费并办理入学注册手续。应缴项目费用及缴费方式具体见《安徽农业大学2025级本科新生学杂费标准及缴费方式告知书》。学校不允许任何人直接向学生收取任何费用，所有收费均通过财政非税收入管理直缴系统进行。咨询电话：0551-65786419。



五、户口迁移。

新生入学可以不转户口。如果需将户口迁移到学校，要提供下列材料：安徽省外需提供户口迁移证(安徽省内需提供户口本原件)、录取通知书、身份证复印件(写上本人联系方式、血型和身高)。户口迁入地址为合肥市蜀山区长江西路130号安徽农业大学。咨询电话：0551-65786431。

2.党组织关系转接：

省内新生党员，党员组织关系转接在系统正常运行的情况下原则上实行全程网上审批，新生党员需由具有省内转接权限的党组织用户发起，提出“申请”，转入中共安徽农业大学XX学院委员会。省外新生党员，需开具纸质介绍信，抬头写中共安徽农业大学委员会，去向为中共安徽农业大学XX学院委员会，介绍信交给录取学院统一审核转接。咨询电话：0551-65786112。



七、档案转接。

新生自带档案在入学报到后交给班级辅导员。若邮寄档案，请于8月29日前寄至：合肥市长江西路130号安徽农业大学档案馆，邮编：230036，收件人：张老师。仅接收EMS或者机要作为档案邮寄方式，普通快递邮寄不予接收。邮寄时请务必在档案袋上注明新生档案、考生姓名、考生号、学院和专业，并确保档案密封完好。专升本考生务必将档案寄送至安徽水利水电职业技术学院，专科学校已经寄往生源地的，请联系原学校调回。由于新生档案较多，接收登记会有延误，无法接受电话查档咨询，请耐心等待或先行查询物流信息作为凭证，档案到校情况待整理后会提供给所在学院，由学院公布。此地址只接收档案，不接收其他个人物品。咨询电话：0551-65786525。

九、专车接站。

学校于8月30、31日7:00—18:00，在合肥火车站和合肥高铁南站出站口安排校车接站。请家长和新同学尽量听从现场工作人员的指挥，有序乘车；妥善保管好自己的行李物品，谨防各种证件、钱物遗失或被窃，确保安全、顺利到校报到。学生也可自己乘公交车、地铁或出租车直接到安徽农业大学报到。



十、入学资格复查。

新生入学后的三个月内，学校将进行入学资格复查，经查不符合录取条件者，取消其入学资格。被安徽农业大学录取的新生，如应征入伍，须办理有关保留入学资格手续。



十一、安全提醒。

报到期间，校园周边人员、车辆较多，新生及家长要提高警惕、加强防范，防止意外事件发生。注重保护个人信息安全，不随意泄露个人重要信息给他人。报到时不让陌生人代办任何手续，不将重要证件与物品交与他人保管。不随意添加陌生人组建的QQ群、微信群，错入或是被拉入请及时退出。学校严禁任何人（包括协助新生办理报到手续的高年级学生）进入宿舍楼进行所谓的“推销”，请同学们不要相信或是购买。学校坚持教育与宗教相分离原则，任何组织和个人不得在校园内进行宗教活动。在校内如与他人发生纠纷，或遇到可疑的人或事时，应及时拨打校保卫处报警电话0551-65786110或直接拨打110报警。学生不得购买摩托车、电动自行车、滑板车等在校园内骑行。在读期间，学生可自行购买“人身意外伤害保险”作为大学生城乡居民医疗保险的有益补充。



十二、咨询交流。

为更好帮助新同学解答问题，各学院新建了官方QQ群，有问题请通过官方QQ群咨询学院负责老师，注意不要随意加入其他群，谨防上当。
