# 生源地信用助学贷款回执单收取

> **所属模块**：新生专栏

各学院：

为了进一步做好生源地信用助学贷款回执收取和录入工作，现将相关事宜通知如下：



  一、安徽省农村商业银行贷款回执单

        学生将贷款回执单验证码上传至智慧安农-学工系统-助学贷款。



  二、国家开发银行贷款回执单

       已办理国家生源地信用助学贷款的学生，可在“迎新系统”选择“绿色通道”缓缴学杂费。请于开学后及时登录“数智安农”平台，进入“智慧学工”模块下的“助学贷款登记”栏目，按照要求准确填报回执验证码及各项应缴费用信息。待贷款资金划拨至个人银行账户后，学校账户会进行学杂费抵扣，剩余部分可作为在校期间的生活费用。

（今年简化了流程，不用打印回执上交）



三、其他类型的外省生源学生贷款回执单

        除了安徽省农商行和国家开发银行之外的其他各银行贷款办理者，请携贷款回执单至学生资助管理中心（勤政楼233办公室）签字盖章后由本人上传至经办银行贷款系统。



  四、相关要求

1.学生资助管理管理中心不单独接收学生个人材料，只接收学院统一上交材料。各学院于工作日每周二、周五上午将收取的回执单交至学生资助管理中心（勤政楼233办公室）。



2.各学院请将收取的安徽省农商行和国家开发银行的贷款回执单按照经办银行分类整理，不要混合在一起。请仔细检查并确保国开行贷款回执单上写明学号和扣款总额。安徽省农商行贷款回执单不需要写相关信息。



3.安徽省国开行贷款回执单提交截止日期为9月20日，安徽省农商行贷款回执单提交日期截止为10月20日。
