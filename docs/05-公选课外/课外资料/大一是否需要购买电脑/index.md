## 内容介绍

大一有信息技术，课堂任务可以在课上完成，如果没有完成的话，学校也有电子阅览室，1
个小时内免费使用，超过时长每小时1块2毛。
因此大一对电脑需求不高，
大一要购买电脑情况如下:
(1)加入院级、校级组织部门，如加入园艺学院学生会办公室，可能需要用一些办公软件，写一写策划书。
