# 🔗 资料链接库

> 体积超过 50 MB 的大文件（高清扫描件、录屏视频、整本教材）集中放这里，不进仓库。

## 为什么单独放

GitHub 对单文件有 **100 MB 硬上限**，仓库体积过大还会让 `git clone` 变得极慢。
所以约定：**小于 50 MB 的直接提交，大于 50 MB 的在这里登记外链。**

仓库里的定时任务每天会巡检一次外部链接，但**网盘链接无法被机器自动判定**，
所以网盘失效需要靠大家手动发现和反馈。
:::
