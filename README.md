## 🗂 资料摆放约定

| 体积 | 放哪里 | 原因 |
| :--- | :--- | :--- |
| **< 50 MB**（普通课件、PDF、真题） | 直接提交进本仓库 | GitHub 单文件硬上限 100 MB，50 MB 是安全线 |
| **> 50 MB**（高清扫描件、录屏视频） | 写进 [13-资料链接库](./docs/13-资料链接库/) | 避免仓库膨胀，克隆变慢 |

每门课目录固定三个子目录：

- `课件/` —— PPT、讲义、课堂板书
- `试卷与答案/` —— 期末真题、模拟卷、答案
- `复习资料/` —— 复习提纲、重点整理、笔记

### ✨ 资料清单会自动生成

把文件丢进上面三个目录就行，**课程页里的清单会自己长出来**：

| 行为 | 说明 |
| :--- | :--- |
| 自动列表 | 展示文件名、类型、大小，可预览的直接在线打开，其余一键下载 |
| 自动排序 | 按数字前缀自然排序，`2-` 排在 `10-` 前面（不会出现 `10` 跑到 `2` 前的错乱） |
| 自动忽略 | `.DS_Store`、`.tmp` 等临时文件与未知格式不入表 |
| 支持子目录 | 目录里再建子目录（如 `复习资料/往年整理/`）也会被递归收录 |
| 构建时同步 | 推送后 CI 自动刷新清单并把资料复制进站点，无需手动打包 |

::: tip 你需要做的
只要**放文件**（可选跑一次 `npm run files` 在本地预览效果）。清单表由脚本维护在页面里的标记区间内，请不要手改那段内容。
:::

## 🛠 本地开发

```bash
# 环境要求：Node.js >= 18（推荐 20+）
npm install           # 安装依赖
npm run docs:dev      # 本地预览 http://localhost:5173/AHAU-Study-Hub/
npm run docs:build    # 构建静态站点到 docs/.vitepress/dist
npm run docs:preview  # 预览构建产物

npm run files         # 扫描课程目录，刷新每门课的资料清单表格
npm run scaffold      # （可选）按模板补齐缺失的目录与 index.md
npm run tree          # 刷新 README 里的目录树
npm run checklinks    # 巡检文档里的外部链接是否失效
```

> 本项目使用 **npm**（锁文件为 `package-lock.json`）。`files:copy` 由 CI 调用，本地一般无需手动执行。

## 🚀 部署说明

站点通过 GitHub Actions 自动部署到 GitHub Pages：

1. 仓库 **Settings → Pages → Source** 选择 **GitHub Actions**（只需设置一次）。
2. 向 `main` 分支推送代码，`deploy.yml` 会自动执行：刷新资料清单 → 构建站点 → 复制资料文件 → 发布。
3. 发布地址：<https://czy1326.github.io/AHAU-Study-Hub/>

若仓库改名，需要同步修改两处 `base`：

- `docs/.vitepress/config.mts` 里的 `base`
- `scripts/gen-courses.mjs` 里的 `BASE`（用于生成资料下载链接）

## 🤝 参与贡献

欢迎提交 Pull Request —— 补一份真题、修一个死链、加一条避坑心得，都算数。

1. Fork 本仓库并新建分支：`git checkout -b add-高数Ⅲ真题`

### 写课程页的建议

每门课的 `index.md` 至少写清三件事：**资料清单**、**考核构成**、**复习路线**。
空模板意义不大，一句「这门课闭卷、重点在第 5 章、原题重复率高」比十个文件夹都值钱。
