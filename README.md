## 🗂 资料摆放约定

| 体积 | 放哪里 | 原因 |
| :--- | :--- | :--- |
| **< 50 MB**（普通课件、PDF、真题） | 直接提交进本仓库 | GitHub 单文件硬上限 100 MB，50 MB 是安全线 |
| **> 50 MB**（高清扫描件、录屏视频） | 写进 [13-资料链接库](./docs/13-资料链接库/) | 避免仓库膨胀，克隆变慢 |

每门课目录固定三个子目录：

- `课件/` —— PPT、讲义、课堂板书
- `试卷与答案/` —— 期末真题、模拟卷、答案
- `复习资料/` —— 复习提纲、重点整理、笔记

## 🛠 本地开发

```bash
# 环境要求：Node.js >= 18（推荐 20+）
pnpm install          # 安装依赖
pnpm docs:dev         # 本地预览 http://localhost:5173/AHAU-Study-Hub/
pnpm docs:build       # 构建静态站点到 docs/.vitepress/dist
pnpm docs:preview     # 预览构建产物

pnpm scaffold         # （可选）按模板补齐缺失的目录与 index.md
pnpm tree             # 刷新 README 里的目录树
pnpm checklinks       # 巡检文档里的外部链接是否失效
```

> 用 npm 也可以：把上面的 `pnpm` 换成 `npm run`，命令名不变。

## 🚀 部署说明

站点通过 GitHub Actions 自动部署到 GitHub Pages：

1. 仓库 **Settings → Pages → Source** 选择 **GitHub Actions**（只需设置一次）。
2. 向 `main` 分支推送代码，`deploy.yml` 会自动构建并发布。
3. 发布地址：<https://czy1326.github.io/AHAU-Study-Hub/>

若仓库改名，需要同步修改 `docs/.vitepress/config.mts` 里的 `base`。

## 🤝 参与贡献

欢迎提交 Pull Request —— 补一份真题、修一个死链、加一条避坑心得，都算数。

1. Fork 本仓库并新建分支：`git checkout -b add-高数A1真题`
2. 按上面的「资料摆放约定」放好文件，并更新对应课程的 `index.md`
3. 提交前跑一下 `pnpm docs:build`，确认没有构建错误 / 死链
4. 发起 Pull Request，说明补了哪门课的什么资料

### 写课程页的建议

每门课的 `index.md` 至少写清三件事：**资料清单**、**考核构成**、**复习路线**。
空模板意义不大，一句「这门课闭卷、重点在第 5 章、原题重复率高」比十个文件夹都值钱。
