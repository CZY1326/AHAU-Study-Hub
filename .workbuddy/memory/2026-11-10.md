## PDF 审计：GitHub 报 "Error rendering embedded code / Invalid PDF"

用户报此错，要求排查。做了五层校验（全部用 python + PyMuPDF）：
1. 头部 %PDF / 尾部 %%EOF / startxref 偏移 —— 50 个已入库 PDF 全过；
2. `doc.is_repaired`（需修复才能打开）—— 0 个；
3. 逐页渲染（约 2000 页，dpi=30）—— 0 页失败；
4. raw.githubusercontent.com HEAD 比对 Content-Length 与本地字节 —— 50 个全部一致，无截断；
5. 超大图片（canvas 上限 16384px）/ 异常页面尺寸 —— 无。

结论：文件本身没问题，是 GitHub blob 预览器（pdf.js）的锅。三种翻车场景：文件大＋网络抖动
一次拉不全、浏览器插件拦截、打开的并非 blob 页面。绕法：URL 末尾加 `?raw=true`（交给浏览器
自带阅读器），或直接走站点 Pages 的下载链接（不经过 GitHub 预览器）。

另：用户后续放入 02-大一第二学期 的 `思想道德与法治课件（2023年版）.pdf` 有 **1610 MB / 1007 页**，
