## 绑定自定义域名 ahaustudyhub.me，base 改为根路径（提交 47853ba）

现象：用户在 Pages 里加了自定义域 ahaustudyhub.me，页面能开但 CSS/JS 全丢。
原因：站点 base 仍是 `/AHAU-Study-Hub/`，自定义域下站点在根路径，
`ahaustudyhub.me/AHAU-Study-Hub/assets/style.css` 直接 404。

关键发现：`czy1326.github.io/AHAU-Study-Hub/xxx` 现在由 GitHub **301 到
`ahaustudyhub.me/xxx`（自动去仓库前缀）**，所以改 base 不会废掉旧链接。

改法（VitePress 不支持相对 base，只能走根路径）：
1. `config.mts`：`base: '/'`，favicon `href: '/logo.svg'`
2. `scripts/gen-courses.mjs`：`BASE = '/'`
3. 新增 `docs/public/CNAME` = `ahaustudyhub.me`（Actions 部署缺它会把域名绑定冲掉）
4. `npm run files` 重生成 32 页课程清单 → 下载链接变 `/资料/...`
5. README / 01-使用指南的网址换成 https://ahaustudyhub.me/

校验：build 通过；dist 全站 235 个下载链接 0 缺失（注意 build 会清 dist，
files:copy 必须在 build 后跑）；线上 `/assets/*.css|js` 200、旧深链 301 到新域同路径 200、
资料 PDF 在新域 200。

用户指出：github.io 与 ahaustudyhub.me 是**同一套 Pages 托管**，且 github.io 已 301 到
自定义域，主域挂了它也跟着挂，不能算备份。认可并改口径：

- 兜底：**GitHub 仓库直连** github.com/CZY1326/AHAU-Study-Hub/tree/main/docs（不经过 Pages）

落位 README 入口表 + 01-使用指南 `::: tip 主网址打不开怎么办`。
若日后要真备份，需另挂一套托管（如 Cloudflare Pages 镜像，但要先处理 21 个 >25MiB 文件）。
